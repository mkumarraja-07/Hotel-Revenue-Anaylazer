# Hotel Revenue Analyzer

A console-based Python project that reads hotel sales data from a CSV file, validates the records, calculates revenue, and shows useful summaries such as total revenue, best day, and revenue by room type. It also displays charts for better analysis.

## Problem Statement

Create a program that reads hotel sales data from a CSV file and analyzes the revenue generated by the hotel. The program should:

- check whether the file exists,
- validate required columns,
- skip invalid rows safely,
- calculate revenue for each record,
- display daily revenue,
- show revenue by room type,
- and generate charts for analysis.

The user should be able to view the results through a simple menu-driven interface.

## Features

- Reads hotel sales data from a CSV file
- Validates required columns: `Date`, `RoomType`, `RoomsSold`, and `Rate`
- Skips invalid rows with warning messages instead of crashing
- Calculates `Revenue = RoomsSold * Rate`
- Displays total revenue and the best day
- Shows revenue by room type with percentage share
- Displays the valid records in a neat table
- Generates bar charts using `matplotlib`
- Handles missing file and bad data gracefully
- Runs in a loop until the user exits

## How the Program Works

1. The program starts in `main()` and prints a simple menu.
2. It calls `load_data()` to check whether the CSV file exists and whether all required columns are present.
3. Each row is checked one by one using a `for` loop.
4. Invalid rows are skipped if:
   - `RoomsSold` or `Rate` is negative,
   - `Date` or `RoomType` is empty,
   - the value is not numeric.
5. A new `Revenue` column is created by multiplying `RoomsSold` and `Rate`.
6. The user chooses one of the following menu options:
   - `1. Daily revenue`
   - `2. Revenue by room type`
   - `3. Show valid records`
   - `4. Exit`
7. The selected function prints the results and, for chart-based options, shows a bar chart.
8. The menu keeps repeating until the user chooses to exit.

## Functions

| Function | What it does |
|---|---|
| `load_data()` | Checks for file existence, validates columns, and filters valid records |
| `daily_revenue(df)` | Displays daily total revenue and best day, then plots a chart |
| `revenue_by_room_type(df)` | Displays revenue by room type and its percentage share |
| `show_all_data(df)` | Displays all valid records from the dataset |
| `main()` | Displays the menu and controls the program flow |

## Rules and Validation

- The CSV file must exist in the same folder as the program.
- The file must contain the columns: `Date`, `RoomType`, `RoomsSold`, and `Rate`.
- Negative numbers in `RoomsSold` or `Rate` are skipped.
- Missing values in `Date` or `RoomType` are skipped.
- Non-numeric values in `RoomsSold` or `Rate` are skipped.
- If no valid records remain, the program shows: `No valid data available.`
- Invalid menu choices show: `Invalid choice. Please enter 1, 2, 3 or 4.`
